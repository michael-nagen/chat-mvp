# What is RAG

RAG means Retrieval-Augmented Generation. It combines retrieval of relevant knowledge with generation by a language model, so answers are based on your own documents rather than the model's memory alone.

# Grounding

Grounded answers should only use the retrieved context and should avoid unsupported claims and hallucinations. When the context does not contain the answer, the tutor should say that relevant information was not found instead of guessing.
